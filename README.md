# 宅理通

宅理通是一套面向普通用户的阳宅风水计算工具，将传统规则整理成可以查询、核对和理解的网页结果。

在线使用：<https://zhailitong.pages.dev/>

## 功能

- **个人计算**：查询命卦、纳音、人命三煞，以及禄位、马位、桃花和贵人等个人方位。
- **通用计算**：按年份查看流年九星、流月盘、五虎杀、天乙贵人、流年文昌和利名星。
- **住宅计算**：根据房屋坐山生成生杀五气宅盘，并结合流年、流月规则显示可催动项目及开始、暂停或停止时间。
- **安床助手**：提供八宅、八门和九星三种安床方法；八宅与八门适用于单身人士，九星适用于已婚夫妇。
- **简易择日**：按年或按月筛选搬家及其他事项的可用日期，并按条件优先级排序。

## 使用说明

项目是纯静态网站，页面文件位于 `dist/`，可直接部署到静态托管服务。

房屋坐向应使用罗盘测量。实际应用还需核对缺角、门窗、走道、房间用途和外部环境等现场条件。简易择日不适用于结婚和动土，所有结果仅供传统文化学习与参考。
